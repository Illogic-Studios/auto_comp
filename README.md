# Auto Comp

<aside>
<img src="/icons/forward_gray.svg" alt="/icons/forward_gray.svg" width="40px" /> Choose the shot to process

We can select the shot path in the user interface. The shot folder has to contain a folder named `render_out`.

</aside>

<aside>
<img src="/icons/forward_gray.svg" alt="/icons/forward_gray.svg" width="40px" /> Select the Unpack Mode that suits you


</aside>

<aside>
<img src="/icons/forward_gray.svg" alt="/icons/forward_gray.svg" width="40px" /> Visualize the layer that are supported by the mode selected


Press the Auto Comp button To automatically generate the composition graph nodes.

</aside>

---

# Shuffle Layer

<aside>
<img src="/icons/forward_gray.svg" alt="/icons/forward_gray.svg" width="40px" /> Visualize the layer of the selected shot

Select layers and press the Shuffle selected layer button to generate the shuffled layer.

</aside>

---

# Shuffle Read Channel

<aside>
<img src="/icons/forward_gray.svg" alt="/icons/forward_gray.svg" width="40px" /> Select a Read in the graph node then select all the channels that have to be shuffled in the list then press Shuffle selected channels button


</aside>

---

# Update Reads

<aside>
<img src="/icons/forward_gray.svg" alt="/icons/forward_gray.svg" width="40px" /> Visualize the version of each layer in the scene. Update to the last version by selecting the layers that have to be shuffled and pressing the Update selected read nodes button


</aside>
